## 1. Executive Summary — Top 5 Systemic Root Causes

These five cross-cutting failure patterns account for the vast majority of why pages feel disconnected or half-built:

| # | Systemic Failure Pattern | Affected Routes | Exact Root Cause |
| :-: | :--- | :--- | :--- |
| **1** | **Split PMS Table Schema (`pms_tasks` v1 vs. `prisma.task` vs. `pms_tasks_v2`)** | `/command`, `/roadmaps`, `/marketing-agent`, `/pods`, `/mindset`, `/pms` | `/pms` (`app/api/pms/route.ts`) reads `pms_lists_v2` / `pms_tasks_v2`, while `/command`, `/marketing-agent`, and `/pods` insert into legacy `pms_tasks` (v1) and `/roadmaps` writes to `prisma.task`. | **3** | **Unpersisted `localStorage`-Only or Missing-API Pages** | `/artifacts` (`25%`), `/org-chart` (`30%`), `/workouts` (`38%`), `/skills` (`40%`), `/roadmaps` (`48%`) | `/artifacts` and `/skills` lack `/api/*` routes completely; `/org-chart` whiteboard wipes edits on reload; `/workouts` ignores its own 4 Postgres `/api/titan/*` routes; `/roadmaps` ignores `/api/roadmaps` and stores trees only in `localStorage`. |
| **4** | **Hardcoded Fake Telemetry & Synthetic Seed Numbers** | `/pods`, `/kpis`, `/budget`, `/caliber-arc`, `/marketing-agent`, `/horizon`, `/workouts` | Hardcoded schedules/biometrics (`HisAndHersDualWheel`, `SAMPLE_MEMBER_METRICS`), fabricated modulo-jitter KPI sparklines, synthetic `0.82 * days` budget shift projections, static `+385% 7d` marketing telemetry, hardcoded Q1–Q4 horizon velocities, and static `+4.2%` / `2026` workout metrics. |

## 3. Prioritized 4-Wave Remediation Plan (Highest Impact First)

### Wave 1 — Fix Cross-Module Plumbing & Silent Contract Bugs *(Unblocks 9 Routes Immediately)*
1. **Unify PMS v2 Write Helper (`lib/pmsV2Writer.ts`):** Route `/command` (`push_frago_to_pms`), `/roadmaps` (`sync_pms`), `/marketing-agent` (`push_to_pms`), and `/pods` (`SharedChoreKanban`) to `public.pms_lists_v2` / `public.pms_tasks_v2` so every cross-module push appears live in `/pms`.
2. **Fix 4 Broken API Contracts:**
   - `/` (`app/page.tsx:178`): read `data.events` from `/api/calendar`, wire `Daily Focus` to `/api/pms`, and show live PMS/Wealth/KPI summary counts.
   - `/calendar` (`app/calendar/page.tsx`): send checklist toggles/adds to `PATCH /api/circadian`, align Yearly Appointment payload keys (`title`, `id`) with `/api/calendar-ops`, and refresh `allCalendarEvents` after Google Grid CRUD.
   - `/workouts` (`app/workouts/page.tsx`): fix `/api/titan/ai-log` payload (`{ input }` / `action`), and wire live session/set logging to existing `/api/titan/{exercises,sessions,sets,templates}` Postgres routes.
   - `/mindset` (`app/api/mindset/route.ts:90`): query `food_entries` / `daily_sitrep_logs` instead of `nutrition_daily_logs`.

### Wave 2 — Eliminate Placeholder Shells & Unpersisted `localStorage` Pages
1. Build `/api/skills/route.ts` + Edit UI on `/skills`, and inject active skills into `/api/copilot`.
2. Build `/api/artifacts/route.ts` + AI generation, Edit/versioning, and real Markdown/HTML preview on `/artifacts`.
3. Persist `/roadmaps` trees to `/api/roadmaps` and `/org-chart` Whiteboard nodes/edges to `/api/architecture/map`, exposing the hidden `mermaid` tab and removing `window.alert()` calls.

### Wave 3 — Complete Missing CRUD & Enforce Real Business Rules
1. **`/family-hub` & `/pods`:** Add `PATCH`/`DELETE` handlers + UI for household entities/schedules/meds/telemetry, expose Tier 3 (`business_team`) tab in `PodContainer`, and replace hardcoded `HisAndHersDualWheel` / `SAMPLE_MEMBER_METRICS` with live DB reads.
2. **`/caliber-arc` & `/budget`:** Enforce `circuitBreakerTripped` server-side in `log_trade`, add trade edit + session CRUD + R-multiple, remove fabricated `0.82 * days` budget shift projections, fix duplicate shift `yearly_appointments` inserts, and wire bank account delete/edit UI.
3. **`/pms`, `/horizon`, `/life-ops`, `/mindset`, `/vault`:** Wire `TaskCalendarView` to `new Date()`, add real DB `tags` + dependency UI in `/pms`, wire Edit/Delete controls on `/horizon`, `/life-ops`, and `/mindset`, and add delete confirmation + slug uniqueness on `/vault`.

### Wave 4 — Live Executive Telemetry Auto-Sync
1. Wire `/kpis` to compute real historical sparklines from `kpi_scorecard_snapshots`, expose the 8 C-suite sectors already defined in `executiveSectorPhysics.ts`, and auto-pull live metrics from `/budget`, `/macro-ops`, `/workouts`, and `/pods`.
2. Sync `/macro-ops` AI log/edit/delete mutations back to `daily_sitrep_logs` and unify macro targets across all cards.
